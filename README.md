# OneClient

OneClient swaps the Minecraft title screen for the OneClient main menu, without the rest of PolyPlus.

- The OneClient logo over the panorama
- Singleplayer, Multiplayer, Realms, Settings and Mods
- Fullscreen and quit buttons in the corner
- One click back to the vanilla menu (you can switch it again in the OneConfig settings)

It can't be installed alongside PolyPlus, which already has this menu.

## Supported versions

- Minecraft 26.3 on Fabric.

OneClient needs [OneConfig](https://modrinth.com/mod/oneconfig) and Fabric Language Kotlin.
